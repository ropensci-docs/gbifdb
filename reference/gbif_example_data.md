# Return a path to the directory containing GBIF example parquet data

Return a path to the directory containing GBIF example parquet data

## Usage

``` r
gbif_example_data()
```

## Value

path to the example occurrence data installed with the package.

## Details

example data is taken from the first 1000 rows of the 2011-11-01 release
of the parquet data.

## Examples

``` r
gbif_example_data()
#> [1] "/github/home/R/x86_64-pc-linux-gnu-library/4.6/gbifdb/extdata/occurrence.parquet"
```
